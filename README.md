# Personal Website

This repository contains a static personal website for GitHub Pages.

## Deploy to GitHub Pages

1. Create a GitHub repository named `Afr1yne.github.io`.
2. Push these files to the `main` branch.
3. In GitHub, open `Settings -> Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Select `main` and `/ (root)`.

The site will be available at `https://Afr1yne.github.io` after GitHub Pages finishes publishing.

## Edit Content

- Main page content: `index.html`
- Visual style: `styles.css`
- Replace placeholder contact text with a public email, resume link, Google Scholar, ORCID, or other links when ready.
